=== Lookup-Funktionen

Lookup-Funktionen suchen Werte in anderen Quellklassen — auch input-übergreifend.

[cols="1,3,3",options="header"]
|===
| Funktion | Signatur | Beschreibung
| `oid` | `(alias) → text` | OID des Quellobjekts
| `bagFirst` | `(alias, bagAttr, valueAttr) → any` | Erstes Attribut aus einem BAG-Attribut
| `lookup` | `(classPath, keyAttr, keyValue, returnAttr) → text` | Unscoped Lookup über alle Inputs; WARNING bei keinem Treffer
| `lookupOptional` | `(classPath, keyAttr, keyValue, returnAttr) → text` | Wie `lookup`, aber still bei keinem Treffer
| `lookupIn` | `(inputId, classPath, keyAttr, keyValue, returnAttr) → text` | Scoped Lookup (nur in `inputId`)
| `existsIn` | `(inputId, classPath, keyAttr, keyValue, ...) → boolean` | Existenz-Prüfung mit mehreren Key/Value-Paaren
|===

==== Beispiele

[source,ilimap]
----
assign {
  // OID des Quellobjekts
  SourceOid = oid(s);

  // Erstes Element aus einem Bag
  ErsteAdresse = bagFirst(g, Adressen, Strasse);

  // Lookup über alle Inputs
  Ort = lookup("AV.Ortschaft", "PLZ", s.PLZ, "Ortsname");

  // Leiser Lookup (keine Warnung)
  Ort = lookupOptional("AV.Ortschaft", "PLZ", s.PLZ, "Ortsname");

  // Lookup in bestimmtem Input
  Region = lookupIn(src, "AV.Region", "BFS_Nr", s.BFS, "Name");

  // Existenz-Prüfung
  HatAdresse = existsIn(src, "AV.Adresse", "GebaeudeId", oid(g));
}
----

==== Reservierter Lookup-Schlüssel

Neben normalen INTERLIS-Attributnamen akzeptieren die Lookup-Funktionen den
reservierten Pseudo-Schlüssel `__objectOid`. Er prüft die OID des Quellobjekts
selbst und ist insbesondere für Referenzen auf polymorphe Parent-Objekte
nützlich:

[source,ilimap]
----
existsIn("src", "Model.Topic.Parent", "__objectOid", oid(child.ParentRef))
----

`__objectOid` wird von der internen `SourceLookupIndex` bereitgestellt. Es ist
kein INTERLIS-Attribut und kommt weder im Modell noch in den Transferdaten vor.
Es darf nur als `keyAttr` in `lookup`, `lookupOptional`, `lookupIn` und
`existsIn` verwendet werden.

Der Runtime-Name `_itf_<Attributname>` ist davon zu unterscheiden. Er dient
intern als Geometrie-Hilfsname für bestimmte INTERLIS-1-/ITF-Fälle und ist
keine unterstützte Mapping-Syntax. Mapping-Profile dürfen sich nicht darauf
stützen.
